# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly.

Instead, please send an email to the project maintainer or create a private advisory on GitHub if possible.

We will do our best to acknowledge your report within 48 hours, and we will send a follow-up detailing the plan to address the issue.
